Descripción detallada

Define el contrato para el envío de mensajes de WhatsApp a través de la WhatsApp Cloud API.

Proporciona métodos para enviar mensajes de texto libre y plantillas aprobadas por Meta, así como notificaciones predefinidas para eventos del sistema (línea completada, cancelada, pedido cancelado).

Todos los métodos retornan Task<bool> — true si el mensaje se envió correctamente, false si el servicio está deshabilitado, faltan datos o hubo un error.

Requiere las siguientes configuraciones en AppConfig.Current:

  • WhatsAppEnabled — habilita/deshabilita el servicio.
  • WhatsAppPhoneNumberId — ID del número de negocio en Meta.
  • WhatsAppApiVersion — versión de la Graph API (default: v21.0).
