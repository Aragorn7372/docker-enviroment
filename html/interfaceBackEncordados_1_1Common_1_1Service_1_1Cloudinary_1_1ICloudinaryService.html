Descripción detallada

Define el contrato para el servicio de gestión de imágenes en Cloudinary.

Proporciona operaciones de subida, obtención de URL y eliminación de imágenes almacenadas en Cloudinary. Todas las imágenes se organizan en carpetas predefinidas (usuarios, talleres, materias) y se sirven con transformaciones optimizadas.

Operaciones:

Operación Método Excepción en error
Subir con nombre explícito UploadAsync CloudinaryUploadException
Subir con nombre auto-generado UploadWithAutoNameAsync CloudinaryUploadException
Eliminar DeleteAsync CloudinaryDeleteException
Obtener URL con transformaciones GetImageUrl, GetImageUrlWithTransformations CloudinaryConfigurationException si no hay configuración
Resolver valor almacenado ResolveImageUrl CloudinaryConfigurationException si no hay configuración

Si no se especifica configuración en CloudinaryOptions.Current, todos los métodos que generan URL lanzan CloudinaryConfigurationException.

Obtiene la URL de una imagen con transformaciones personalizadas.

Usa Cloudinary.Api.UrlImgUp con transformaciones Width, Height, Crop, Quality y FetchFormat definidas en CloudinaryOptions.Current.Transformations. Si no se especifican width/height, se usan los valores por defecto de configuración (800x600).

Parámetros
publicIdPublic ID de la imagen.
widthAncho en píxeles (opcional, default: configurado).
heightAlto en píxeles (opcional, default: configurado).
Devuelve

◆ ResolveImageUrl()

string BackEncordados.Common.Service.Cloudinary.ICloudinaryService.ResolveImageUrl ( string  storedValue,
string  folder 
)

Resuelve el valor almacenado en base de datos a una URL completa de imagen.

Lógica de resolución:

  • Si storedValue es vacío → imagen predeterminada de la carpeta.
  • Si comienza con "http" → se devuelve tal cual (URL externa o absoluta).
  • En cualquier otro caso → se trata como PublicId y se aplican transformaciones.
Parámetros
storedValueValor almacenado en BD (puede ser vacío, URL completa o PublicId).
folderCarpeta Cloudinary para obtener imagen por defecto si es necesario.
Devuelve
URL resuelta.
