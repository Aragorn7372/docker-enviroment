Middleware global de manejo de excepciones que captura errores no controlados del pipeline de ASP.NET Core y genera respuestas HTTP JSON consistentes.

Se ejecuta como middleware terminal para errores: captura cualquier excepción no manejada por los controladores u otros middlewares, genera un ID de seguimiento único, registra el error con logging estructurado, y retorna una respuesta JSON normalizada al cliente.

Estructura de la respuesta JSON:

Campo Tipo Descripción
errorId string Identificador único de 8 caracteres hexadecimales para trazabilidad.
message string Mensaje descriptivo del error adaptado al tipo de excepción.
errorType string Categoría del error (ej: "UnauthorizedError", "ValidationError", "InternalError").
timestamp string (ISO 8601) Marca de tiempo UTC en formato yyyy-MM-ddTHH:mm:ss.fffffffZ.
path string Ruta de la solicitud que originó el error (ej: /api/excel/export/...).
method string Verbo HTTP de la solicitud (GET, POST, PUT, DELETE, etc.).
errors Dictionary (nullable) Detalles adicionales de errores de validación (actualmente no implementado, reservado para expansión futura). Se omite si es null.

Mapeo de excepciones a códigos HTTP:

Excepción HTTP Status errorType Message
UnauthorizedAccessException 401 UnauthorizedError "No autorizado"
ArgumentException 400 ValidationError ex.Message
CloudinaryUploadException 422 CloudinaryUploadError ex.Message
CloudinaryDeleteException 422 CloudinaryDeleteError ex.Message
CloudinaryConfigurationException 500 CloudinaryConfigurationError ex.Message
CloudinaryInvalidParameterException 400 CloudinaryInvalidParameterError ex.Message
DbUpdateException 400 DataIntegrityError "Los datos enviados contienen errores de integridad..."
TimeoutException 408 InternalError "Tiempo de espera agotado"
Exception (general) 500 InternalError "Ha ocurrido un error interno"

Configuración de serialización JSON:

  • PropertyNamingPolicy = JsonNamingPolicy.CamelCase: nombres de propiedad en camelCase.
  • DefaultIgnoreCondition = JsonIgnoreCondition.WhenWritingNull: omite propiedades nulas (como errors cuando no hay detalles de validación).

Para registrar este middleware en el pipeline de la aplicación, usar app.UseGlobalExceptionHandler() en Program.cs antes de otros middlewares que puedan generar errores.

Parámetros
nextSiguiente middleware en el pipeline de ASP.NET Core.
loggerLogger para registro estructurado de errores con ErrorId y Message.

Punto de entrada del middleware. Ejecuta el pipeline y captura excepciones no manejadas.

Flujo:

  1. Ejecuta el siguiente middleware en el pipeline de ASP.NET Core mediante await next(context).
  2. Si la ejecución es exitosa, el método retorna sin cambios en la respuesta.
  3. Si ocurre cualquier excepción, genera un identificador único de error de 8 caracteres hexadecimales a partir de Guid.NewGuid().ToString()[..8].
  4. Registra el error con logger.LogError incluyendo el ErrorId y el mensaje como propiedades estructuradas para facilitar la búsqueda en sistemas de logging.
  5. Delega en HandleExceptionAsync para construir y enviar la respuesta JSON con el código HTTP y mensaje apropiados según el tipo de excepción.
  6. No relanza la excepción: el middleware actúa como terminal para errores, evitando que lleguen al cliente como respuestas HTML por defecto de ASP.NET Core.
Parámetros
contextContexto HTTP de la solicitud actual.

Construye y envía una respuesta JSON estructurada según el tipo de excepción capturada.

Flujo:

  1. Establece el Content-Type de la respuesta como application/json.
  2. Usa un switch expression para mapear el tipo de excepción a una tupla de (statusCode, message, errors, errorType):

Mapeo detallado:

Excepción Código Mensaje Tipo de error
UnauthorizedAccessException 401 "No autorizado" UnauthorizedError
ArgumentException 400 argument.Message (mensaje original) ValidationError
CloudinaryUploadException 422 uploadEx.Message CloudinaryUploadError
CloudinaryDeleteException 422 deleteEx.Message CloudinaryDeleteError
CloudinaryConfigurationException 500 configEx.Message CloudinaryConfigurationError
CloudinaryInvalidParameterException 400 paramEx.Message CloudinaryInvalidParameterError
DbUpdateException 400 "Los datos enviados contienen errores de integridad (duplicados o estructura inválida)" DataIntegrityError
TimeoutException 408 "Tiempo de espera agotado" InternalError
Exception (cualquier otra) 500 "Ha ocurrido un error interno" InternalError

Luego construye un objeto anónimo con 7 propiedades serializado con System.Text.Json usando camelCase y omisión de propiedades nulas, y lo escribe en el cuerpo de la respuesta HTTP.
