Descripción detallada

Tests unitarios para UlidRouteConstraint, la constraint de ruta que valida que un parámetro de ruta sea un ULID válido en ASP.NET Core.

Verifica la implementación de IRouteConstraint.Match cubriendo todos los escenarios posibles:

  • ULID válido — debe retornar true.
  • String inválido — debe retornar false.
  • Tipo no-string (int) — debe retornar false.
  • Clave ausente en el diccionario — debe retornar false.
  • String vacío — debe retornar false.
  • Valor nulo — debe retornar false.

Usa FluentAssertions para las aserciones y NUnit como framework de测试.
