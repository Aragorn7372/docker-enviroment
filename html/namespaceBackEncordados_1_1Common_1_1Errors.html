record BackEncordados.Common.Errors.DomainErrors ( string  Error)

Record base para todos los errores de dominio de la aplicación. Implementa el patrón Result mediante CSharpFunctionalExtensions, permitiendo propagar errores de forma explícita como tipos en lugar de excepciones.

Todos los errores específicos del dominio heredan de este record, formando una jerarquía que permite al GlobalExceptionHandler mapear cada tipo a un código HTTP específico (400, 401, 404, 409, 422, 500).

Jerarquía de errores:

  • AuthError → autenticación y autorización (401, 409, 400).
  • CuerdaError → cuerdas/tensores (404, 409, 400).
  • MaterialError → materiales (404, 409, 400).
  • PurchasedErrors → pedidos (404, 409, 400).
  • TournamentsErrors → torneos (404, 409, 400).

Uso típico con Result Pattern:

return Result.Failure<T, CuerdaNotFoundError>(new CuerdaNotFoundError());
Parámetros
ErrorMensaje descriptivo del error ocurrido. Se propaga a través de la jerarquía de herencia.

Mensaje descriptivo del error ocurrido. Se establece en el constructor base y puede ser sobrescrito por los registros derivados. Es el único campo expuesto en las respuestas de error de la API.

"Cuerda not found", "Credenciales inválidas", "El torneo no existe"
