Descripción detallada

Validador FluentValidation para MaterialPatchDto.

Reglas de validación (solo aplican cuando el campo es proporcionado):

  • Stock — si >= 0, debe ser un número positivo.
  • Precio — si >= 0, debe ser mayor que 0.
  • Type — si no está vacío, debe ser un valor válido de MaterialType.
