Descripción detallada

Interceptor de EF Core que incrementa automáticamente el token de concurrencia Version de las entidades User cada vez que se modifican.

Este interceptor se registra en el pipeline de AddDbContext y se ejecuta tanto en operaciones síncronas como asíncronas antes de guardar los cambios en la base de datos.

Comportamiento:

  • Detecta entidades User con estado Modified en el ChangeTracker.
  • Lee el valor original de la propiedad Version y lo incrementa en 1.
  • EF Core utiliza este valor en la cláusula WHERE del UPDATE para detectar conflictos de concurrencia optimista.

Relación con UserDbContext:

  • La propiedad Version se configura como IsConcurrencyToken() en UserDbContext.OnModelCreating.
  • Sin este interceptor, el token de concurrencia nunca se incrementaría automáticamente.
