DTO de filtro para la búsqueda paginada de materiales.

Se utiliza en el endpoint GET del MaterialsController para aplicar filtros, paginación y ordenamiento a la consulta de materiales.

Campos:

  • TournamentId — filtra por torneo específico (opcional).
  • Search — término de búsqueda general (opcional, vacío por defecto).
  • Page — número de página (0-indexed, default 0).
  • Size — tamaño de página (default 10).
  • SortBy — campo de ordenamiento (default "name").
  • Direction — dirección "asc" o "desc" (default "asc").
