Descripción detallada

Implementación de IJwtTokenExtractor para extraer información de tokens JWT sin validar la firma, útil para inspección de tokens existentes.

Proporciona siete métodos de extracción:

Método Propósito
ExtractUserId Extrae el ID de usuario (NameIdentifier, nameid o Sub) como long?.
ExtractRole Extrae el rol del usuario (Role o role).
IsAdmin Verifica si el rol es "admin" (case-insensitive).
ExtractUserInfo Tuple con UserId, IsAdmin y Role.
ExtractClaims Extrae todos los claims como ClaimsPrincipal (con fallback a parseo manual del payload).
ExtractEmail Extrae el email del token.
IsValidTokenFormat Valida el formato estructural del JWT (3 partes separadas por punto).

No realiza validación criptográfica de la firma — solo lectura de claims del token.

Normaliza los tipos de claim: nameid/sub → NameIdentifier, email → Email, role/roles → Role, name → Name.

◆ ExtractClaims()

ClaimsPrincipal? BackEncordados.Usuarios.Service.Auth.JwtTokenExtractor.ExtractClaims ( string  token)
inline

Extrae todos los claims del token JWT como un ClaimsPrincipal.

Estrategia de extracción:

  1. Intenta parsear el token con JwtSecurityTokenHandler.ReadJwtToken.
  2. Si el token es válido, extrae claims normalizando los tipos.
  3. Si falla el parseo, intenta leer manualmente el payload Base64Url y extraer propiedades de tipo string.
  4. Si ambas estrategias fallan, retorna null.
Parámetros
tokenToken JWT del que extraer los claims.
Devuelve
ClaimsPrincipal con los claims extraídos, o null si el token es inválido.

bool BackEncordados.Usuarios.Service.Auth.JwtTokenExtractor.IsValidTokenFormat ( string  token)
inline

Valida el formato estructural de un token JWT sin verificar la firma.

Verifica que el token tenga tres partes separadas por punto (header, payload, signature).

Si no tiene firma, verifica que el algoritmo en el header sea "none" (token sin firmar).

Parámetros
tokenToken JWT a validar estructuralmente.
Devuelve
true si el formato es válido, false en caso contrario.
