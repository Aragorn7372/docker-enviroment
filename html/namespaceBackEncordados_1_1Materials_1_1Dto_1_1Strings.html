DTO de filtro para la búsqueda paginada de cuerdas.

Se utiliza en el endpoint GET del CuerdasController para aplicar filtros, paginación y ordenamiento a la consulta de cuerdas.

Campos:

  • TournamentId — filtra por torneo específico (opcional).
  • Search — término de búsqueda general (opcional).
  • Page — número de página (0-indexed, default 0).
  • Size — tamaño de página (default 10).
  • SortBy — campo de ordenamiento (default "name").
  • Direction — dirección "asc" o "desc" (default "asc").

DTO de salida que representa una cuerda del inventario para las respuestas de la API.

Se utiliza en los endpoints GET del CuerdasController para devolver los datos serializados de la cuerda al cliente.

Propiedades:

Propiedad Tipo Descripción
Id long ID numérico de la cuerda.
TournamentId Ulid ID del torneo asociado.
Marca string Marca de la cuerda.
Modelo string Modelo de la cuerda.
Stock int Cantidad disponible.
Precio double Precio unitario.
StringFormat string Formato "Reel" o "Set".
StringsType string Tipo de cuerda.
Calibre double Grosor en mm.
ImageUrl string URL de la imagen.
