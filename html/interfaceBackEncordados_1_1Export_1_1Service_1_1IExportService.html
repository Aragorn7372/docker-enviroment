Descripción detallada

Contrato del servicio de lógica de negocio para la exportación e importación completa de la base de datos del sistema en formato ZIP.

Actúa como fachada (Facade pattern) que orquesta las operaciones entre el repositorio de datos (IExportRepository) y el administrador de archivos ZIP (IExportArchiveManager).

Métodos del contrato:

Método Retorno Propósito
ExportDatabaseAsync byte[] Obtiene todas las entidades de la base de datos a través del repositorio y las comprime en un archivo ZIP mediante el archive manager.
GetManifestAsync ExportManifestDto Lee únicamente el archivo manifest.json del interior de un ZIP sin deserializar los datos completos de las entidades. Operación ligera para previsualización.
ImportDatabaseAsync Task Extrae el contenido de un archivo ZIP, limpia todos los datos existentes en la base de datos y luego importa los nuevos datos en el orden correcto de dependencias. La transaccionalidad es manejada por el decorador [Transactional] en el controlador.

Flujo de importación:

  1. Extrae ZIP → ExportDataDto con todas las entidades.
  2. Limpia BD completa (orden inverso de dependencias).
  3. Importa datos (orden directo: torneos → usuarios → materiales → cuerdas → pedidos).

◆ ExportDatabaseAsync()

Task< byte[]> BackEncordados.Export.Service.IExportService.ExportDatabaseAsync ( )

Exporta toda la base de datos como un archivo ZIP.

Flujo:

  1. Llama a IExportRepository.GetAllDataAsync para obtener todas las entidades de los cuatro DbContexts.
  2. Delega en IExportArchiveManager.CreateZipAsync la serialización a JSON y compresión en ZIP.
  3. Retorna el arreglo de bytes del ZIP generado.

El ZIP resultante contiene un archivo JSON por módulo (users, tournaments, materials, cuerdas, orders) más un manifest.json con metadatos.

Devuelve
Arreglo de bytes con el archivo ZIP de la base de datos completa.

◆ GetManifestAsync()

Task< ExportManifestDto > BackEncordados.Export.Service.IExportService.GetManifestAsync ( byte[]  zipData)

Obtiene el manifest de un archivo ZIP de exportación sin extraer los datos completos.

Método ligero que delega directamente en IExportArchiveManager.GetManifestAsync. Lee únicamente el archivo manifest.json del interior del ZIP, que contiene la fecha de exportación y la lista de entidades incluidas con sus cantidades.

Útil para previsualizar el contenido de un archivo ZIP antes de decidir si importarlo. No modifica la base de datos ni consume tanta memoria como una importación completa.

Parámetros
zipDataArreglo de bytes del archivo ZIP a inspeccionar.
Devuelve
Manifest con metadatos de la exportación.

◆ ImportDatabaseAsync()

Task BackEncordados.Export.Service.IExportService.ImportDatabaseAsync ( Stream  zipStream)

Importa datos desde un archivo ZIP a la base de datos.

Flujo detallado:

  1. Extrae el contenido del ZIP mediante IExportArchiveManager.ExtractZipAsync, que descomprime y deserializa todos los archivos JSON a un ExportDataDto.
  2. Limpia todos los datos existentes mediante IExportRepository.ClearAllDataAsync, que selecciona automáticamente la estrategia de borrado según el proveedor de base de datos (InMemory o producción).
  3. Importa los nuevos datos mediante IExportRepository.ImportDataAsync, que respeta el orden de dependencias: torneos (con manejo especial de WorkerMachineAssignments), luego usuarios, materiales, cuerdas y finalmente pedidos.

Nota transaccional: Este método no maneja transacciones por sí mismo. La transaccionalidad es proporcionada por el decorador [Transactional] en el método ExportController.Import, que coordina un commit/rollback manual sobre los cuatro DbContexts.

Parámetros
zipStreamStream del archivo ZIP (.zip) a importar.
