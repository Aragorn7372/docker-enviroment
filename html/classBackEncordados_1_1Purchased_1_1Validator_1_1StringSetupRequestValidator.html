 Defines validation rules for a string setup when creating a line item.
 

Descripción detallada

Validates a StringSetupDto for the creation (not patch) scenario.

In creation mode, vertical string name (StringV) is required, tension must be within the realistic 5–40 kg range, and pre-stretch must be 0–20 %. Horizontal fields are optional because some racquets use a one-piece stringing method.

When horizontal values ARE provided:

  • TensionH must be between 5.0 and 40.0 kg if greater than 0.
  • PreStetchH must be between 0 and 20 % if greater than 0.

This validator is used by PedidoLineaRequestValidator for the StringSetup property. For patch scenarios (where all core fields are required), see StringSetupPatchValidator.
