Tests Vitest
Linting / formato Prettier + ESLint

Inicio rápido

Prerrequisitos

  • Node.js 22+
  • npm 11+

Instalación

npm install

Desarrollo

npm run start
# → http://localhost:4200

Build de producción

npm run build
# Salida en dist/front-encordados/

Tests

npm run test

Docker

El Dockerfile usa build multietapa:

Etapa Propósito
build Compila la aplicación Angular con npm run build -- --configuration production
production Sirve los archivos compilados con Nginx
docker build -t front-encordados .
docker run -p 80:80 front-encordados

Inyección de variables en runtime

El contenedor ejecuta generate-env.js antes de arrancar Nginx. Este script reemplaza placeholders en los archivos JS compilados con las variables de entorno del contenedor, permitiendo cambiar la URL de la API sin recompilar la imagen.

Nginx

El servidor dentro del contenedor usa nginx.conf con:

  • Servicio de archivos estáticos desde /usr/share/nginx/html
  • Redirección de rutas SPA (fallback a index.html)
  • Cabeceras de caché para assets con huella digital

Build pipeline

npm ci (instalación exacta)
→ ng build --configuration production
→ Compilación TypeScript + Tailwind + PostCSS
→ Generación de bundles (principal, lazy chunks, polyfills)
→ Aplicación del Service Worker (ngsw-config.json)
→ Minificación y hashing de assets
→ generate-env.js (inyección de variables de entorno)
→ Nginx (servir archivos estáticos)

Interceptores

El flujo de una petición HTTP pasa por los siguientes interceptores de Angular:

Petición HTTP
→ auth.interceptor.ts
Inyecta el header Authorization: Bearer <JWT>
Si el token ha expirado, redirige a /login
→ offline.interceptor.ts
Si hay conexión: deja pasar la petición y cachea la respuesta en IndexedDB
Si no hay conexión: sirve la respuesta desde IndexedDB (hasta 7 días de antigüedad)
→ api.service.ts
Aplica timeout, headers genéricos (Content-Type, Accept)
Manejo centralizado de errores (toast notification)

Funcionalidades destacadas

Tablero Kanban en tiempo real

La página de pedidos (/pedidos) muestra tarjetas en columnas (En Proceso / Listos) que se actualizan automáticamente vía SignalR. Los encordadores pueden arrastrar y soltar tarjetas con Angular CDK para cambiar el estado sin recargar.

Escáner QR

El componente scanner usa la cámara del dispositivo vía @zxing/browser para leer los códigos QR impresos en los tickets de pedido, abriendo directamente el detalle del pedido escaneado.

Generación de códigos

pedido-codes genera códigos QR y de barras (JSBarcode / qrcode) para cada pedido, listos para imprimir o mostrar en pantalla.

Informes y gráficas

La página de informes (/informes) renderiza estadísticas con ApexCharts: pedidos por estado, materiales más usados, rendimiento por encordador, etc.

Búsqueda global

global-search permite buscar pedidos, contactos y materiales desde cualquier punto de la aplicación.

Estrategia offline y PWA

Service Worker

ngsw-config.json configura el Service Worker de Angular con:

  • Precarga del shell de la aplicación y assets estáticos
  • Estrategia freshness para peticiones a /api/** — primero red, con fallback a caché de hasta 7 días
  • Instalación como PWA (manifest en public/manifest.webmanifest)

IndexedDB (Dexie)

Cuando no hay red, offline.interceptor.ts intercepta las peticiones HTTP y sirve datos desde offline-db.ts (esquema Dexie con tablas para pedidos, materiales, cuerdas, usuarios, torneos).

Sincronización

offline-sync.service.ts mantiene una cola de cambios realizados sin conexión. Al recuperar la conectividad, reproduce los cambios pendientes contra la API en segundo plano.

Convenciones de código

  • Standalone components en todos los archivos — sin NgModules
  • Lazy loading en todas las páginas (ver app.routes.ts)
  • Prettier con configuración en .prettierrc para formato consistente
  • PostCSS configurado en postcss.config.js (Tailwind + autoprefixer)
  • .editorconfig para mantener indentación y saltos de línea uniformes
  • Sufijos de archivo: .page.ts para páginas, .component.ts para componentes reutilizables, .service.ts para servicios
