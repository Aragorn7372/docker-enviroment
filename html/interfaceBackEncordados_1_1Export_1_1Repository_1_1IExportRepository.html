Descripción detallada

Contrato del repositorio para la exportación e importación global de todas las entidades de la base de datos.

Opera sobre los cuatro DbContexts de la aplicación para obtener, limpiar y reimportar todos los datos del sistema. Utilizado por IExportService para las operaciones de respaldo y restauración.

Métodos del contrato:

Método Retorno Propósito
GetAllDataAsync Task<ExportDataDto> Obtiene todas las entidades de los cuatro DbContexts con IgnoreQueryFilters() para incluir registros soft-deleted, y carga PedidoLineas por separado para asignarlas manualmente a cada pedido.
ClearAllDataAsync Task Elimina todos los datos en orden inverso de dependencias. Usa estrategias diferentes según el proveedor de base de datos (InMemory → RemoveRange, producción → ExecuteDeleteAsync).
ImportDataAsync Task Importa datos en orden correcto respetando FK: torneos primero (con manejo especial de WorkerMachineAssignments), luego users, materials, cuerdas y finalmente pedidos.

Orden de operaciones:

  • Exportación: no requiere orden específico (solo lectura).
  • Limpieza: orden inverso (Pedidos → Materials/Cuerdas → Users → Tournaments).
  • Importación: orden directo (Tournaments → Users → Materials → Cuerdas → Pedidos).

◆ ClearAllDataAsync()

Task BackEncordados.Export.Repository.IExportRepository.ClearAllDataAsync ( )

Elimina todos los datos de la base de datos en orden inverso de dependencias.

Selecciona automáticamente la estrategia de borrado según el proveedor de base de datos:

Proveedor Estrategia Método
InMemory RemoveRange + SaveChangesAsync ClearAllDataInMemoryAsync
Producción (PostgreSQL, SQL Server, etc.) ExecuteDeleteAsync para tablas sin restricciones FK batch, RemoveRange + SaveChangesAsync para tablas con dependencias ClearAllDataProductionAsync

Orden de eliminación: Pedidos (y líneas) → Materials/Cuerdas → Users → Tournaments. Este orden respeta las restricciones de clave foránea.

◆ GetAllDataAsync()

Task< ExportDataDto > BackEncordados.Export.Repository.IExportRepository.GetAllDataAsync ( )

Obtiene todas las entidades de la base de datos para exportación.

Consulta los cuatro DbContexts usando IgnoreQueryFilters() para incluir registros marcados como eliminados (soft delete). Usa AsNoTracking() en todas las consultas por ser de solo lectura.

Las líneas de pedido (PedidoLineas) se cargan por separado en un Lookup y se asignan manualmente a cada pedido, en lugar de usar Include(), para evitar arrastrar relaciones de navegación circulares que complican la serialización.

Devuelve
DTO con todas las listas de entidades pobladas.

◆ ImportDataAsync()

Task BackEncordados.Export.Repository.IExportRepository.ImportDataAsync ( ExportDataDto  data)

Importa todas las entidades en la base de datos respetando el orden de dependencias.

Orden de importación:

  1. Torneos — Primero porque otras entidades (Users) pueden referenciarlos. Requiere manejo especial de WorkerMachineAssignments (OwnsMany): se extraen antes de insertar el torneo y se reasignan post-insert con IDs numéricos secuenciales, ya que el ValueConverter de OwnsMany requiere IDs únicos.
  2. Usuarios — Después de torneos. Pueden tener TournamentId opcional.
  3. Materiales — No tienen dependencias de otras entidades recién insertadas.
  4. Cuerdas — No tienen dependencias de otras entidades recién insertadas.
  5. Pedidos — Último porque dependen de usuarios (PlayerId, AssignedTo) y torneos (TournamentId). Incluyen líneas de pedido anidadas.
Parámetros
dataDTO con todas las listas de entidades a importar.
