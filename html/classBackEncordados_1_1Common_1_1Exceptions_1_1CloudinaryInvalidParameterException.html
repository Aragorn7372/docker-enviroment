Descripción detallada

Excepción que se produce cuando se proporciona un parámetro inválido a una operación de Cloudinary.

Incluye automáticamente el prefijo "Parámetro inválido para Cloudinary: " en el mensaje, concatenándolo con el mensaje específico recibido.

Escenarios típicos:

  • URL de imagen vacía o con formato incorrecto.
  • publicId nulo o vacío al intentar eliminar una imagen.
  • Parámetros de transformación de imagen inválidos (width, height, crop).
  • Folder de destino inválido o inexistente.

Mapeado por GlobalExceptionHandler a HTTP 400 Bad Request con errorType "CloudinaryInvalidParameterError".
