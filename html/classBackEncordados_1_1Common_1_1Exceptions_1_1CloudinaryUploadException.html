Descripción detallada

Excepción que se produce cuando falla la subida de una imagen a Cloudinary.

Incluye automáticamente el prefijo "Error al subir imagen a Cloudinary: " en el mensaje, concatenándolo con el mensaje específico recibido.

Escenarios típicos:

  • Archivo de imagen corrupto o en formato no soportado.
  • Tamaño de archivo excede el límite configurado en Cloudinary.
  • Error de conexión con la API de Cloudinary.
  • Credenciales de API inválidas o expiradas.

Mapeado por GlobalExceptionHandler a HTTP 422 Unprocessable Entity con errorType "CloudinaryUploadError".
