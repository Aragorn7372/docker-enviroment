Descripción detallada

Contrato del servicio de lógica de negocio para exportación e importación de datos de torneos en formato Excel.

Actúa como fachada (Facade pattern) que orquesta las operaciones entre el repositorio de datos (IExcelRepository), el administrador de archivos Excel (IExcelArchiveManager), y los servicios de negocio de cada módulo (usuarios, materiales, cuerdas, torneos, pedidos).

Métodos del contrato:

Método Retorno Rol requerido Propósito
ExportTournamentAsync byte[] Supervisor Exporta resumen simple del torneo (jugadores, raquetas, precios).
ExportAdvancedAsync byte[] Owner/Admin Exporta datos multi-hoja según tipos seleccionados.
ImportAsync ExcelImportResultDto Owner/Admin Importa datos desde un archivo Excel subido.

Los métodos de exportación retornan el archivo Excel como arreglo de bytes (byte[]) listo para ser servido como FileContentResult en el controlador. El método de importación retorna un DTO con contadores de registros creados/actualizados y una lista de errores ocurridos durante el proceso.

Todos los métodos lanzan UnauthorizedAccessException si el usuario no tiene permisos para la operación solicitada.

Exporta datos multi-hoja de un torneo según los tipos especificados.

Los administradores (ADMIN) tienen acceso directo sin verificación adicional. Los propietarios (OWNER) deben ser verificados como dueños del torneo.

Flujo:

  1. Verifica permisos según el rol (ADMIN bypass, OWNER check contra repositorio).
  2. Filtra los tipos solicitados contra la lista blanca de tipos válidos ("users", "materials", "cuerdas", "tournament", "pedidos").
  3. Si types está vacío, se exportan todos los tipos disponibles.
  4. Obtiene los datos multi-hoja desde el repositorio.
  5. Delega en IExcelArchiveManager.CreateAdvancedExcelAsync la generación del Excel.
Parámetros
userIdID del usuario que solicita la exportación (ULID).
tournamentIdID del torneo a exportar (ULID).
typesLista de tipos de datos a incluir. Valores válidos: "users", "materials", "cuerdas", "tournament", "pedidos".
roleRol del usuario (ADMIN u OWNER).
Devuelve
Arreglo de bytes con el archivo Excel multi-hoja generado.
Excepciones
UnauthorizedAccessExceptionEl usuario no tiene permisos para exportar este torneo.

Ulid  tournamentId

Exporta un resumen simple del torneo en formato Excel.

Verifica que el usuario sea supervisor del torneo antes de exportar. El resumen incluye una fila por jugador con la cantidad de raquetas encordadas y el precio total acumulado.

Flujo:

  1. Verifica permisos de supervisor mediante IExcelRepository.IsUserSupervisorOfTournamentAsync.
  2. Obtiene los datos agregados del torneo desde el repositorio.
  3. Obtiene el nombre del torneo desde TalleresDbContext para el título del archivo.
  4. Delega en IExcelArchiveManager.CreateExcelAsync la generación del archivo Excel.
Parámetros
userIdID del usuario que solicita la exportación (ULID).
tournamentIdID del torneo a exportar (ULID).
Devuelve
Arreglo de bytes con el archivo Excel generado.
Excepciones
UnauthorizedAccessExceptionEl usuario no es supervisor del torneo.

Importa datos desde un archivo Excel a un torneo existente.

Lee el archivo Excel desde el stream, parsea los datos por módulo, y para cada registro decide si actualizar (si existe ID) o crear (si no existe). Los errores individuales por fila no detienen el proceso; se acumulan en ExcelImportResultDto.Errors.

Flujo:

  1. Verifica permisos según el rol (ADMIN bypass, OWNER check contra repositorio).
  2. Filtra los tipos solicitados contra la lista blanca de tipos válidos.
  3. Lee y parsea el archivo Excel mediante IExcelArchiveManager.ReadExcelAsync.
  4. Importa secuencialmente cada módulo: users, materials, cuerdas, tournament, pedidos.
  5. Retorna un DTO con contadores de registros creados/actualizados y errores.
Parámetros
userIdID del usuario que solicita la importación (ULID).
tournamentIdID del torneo destino (ULID).
typesLista de tipos de datos a importar. Valores válidos: "users", "materials", "cuerdas", "tournament", "pedidos".
roleRol del usuario (ADMIN u OWNER).
excelStreamStream del archivo Excel (.xlsx) a importar.
Devuelve
Resultado de la importación con contadores y lista de errores.
Excepciones
UnauthorizedAccessExceptionEl usuario no tiene permisos para importar a este torneo.
