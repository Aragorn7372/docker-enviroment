Descripción detallada

Opciones de configuración de la aplicación leídas desde la sección "App" del archivo appsettings.json.

POCO con valores predeterminados que se sobreescriben desde la configuración durante el arranque. Incluye ajustes de URLs del frontend, expiración de tokens temporales y credenciales de la API de WhatsApp Cloud.

Mapeo con appsettings.json:

Propiedad Clave en JSON Default Uso
FrontendUrl App:FrontendUrl http://localhost:3000 URL base del frontend para enlaces en correos (reset password, confirmación).
ServerUrl App:ServerUrl "" URL base del servidor para enlaces de retorno.
PasswordResetExpiryMinutes App:PasswordResetExpiryMinutes 60 Minutos de validez del token de reset de contraseña.
EmailOtpExpiryMinutes App:EmailOtpExpiryMinutes 15 Minutos de validez del OTP enviado por email.
WhatsAppEnabled App:WhatsAppEnabled false Habilita/deshabilita el envío de mensajes por WhatsApp Cloud API.
WhatsAppPhoneNumberId App:WhatsAppPhoneNumberId "" ID del número de teléfono registrado en Meta Business.
WhatsAppAccessToken App:WhatsAppAccessToken "" Token de acceso Bearer para autenticación contra Graph API de Meta.
WhatsAppApiVersion App:WhatsAppApiVersion v25.0 Versión de la Graph API de Meta (ej: v25.0, v26.0).

Nota de seguridad: Las propiedades WhatsAppAccessToken contienen credenciales sensibles. En producción deben almacenarse en User Secrets, Azure Key Vault o variables de entorno, no en el archivo appsettings.json directamente.
