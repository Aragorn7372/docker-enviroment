Descripción detallada

DTO contenedor que agrupa todas las entidades del sistema para exportación e importación completa de la base de datos en formato ZIP.

Utilizado por IExportArchiveManager y IExportService para serializar y deserializar la base de datos completa a/desde archivos JSON organizados por módulo dentro de un archivo ZIP.

Correspondencia con archivos del ZIP:

Propiedad Archivo JSON Entidad Módulo
Users users.json Usuarios.Model.User Usuarios del sistema.
Tournaments tournaments.json Talleres.Model.Tournaments Torneos con sus listas de supervisores y trabajadores.
Materials materials.json Materials.Model.Material Materiales de encordado (grips, overgrips, etc.).
Cuerdas cuerdas.json Materials.Model.Cuerdas Cuerdas con calibre, formato y tipo.
Pedidos orders.json Purchased.Model.Pedidos Pedidos con líneas de pedido incluidas (relaciones de navegación de EF Core).

Nota técnica: La propiedad Pedidos incluye las líneas de pedido (PedidoLineas) a través de las relaciones de navegación de Entity Framework Core. La serialización con Newtonsoft.Json (configurado con ReferenceLoopHandling.Ignore) maneja las referencias circulares entre entidades.
