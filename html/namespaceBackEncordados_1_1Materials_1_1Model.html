◆ FormatoCuerda

enum BackEncordados.Materials.Model.FormatoCuerda

Enum que representa el formato o presentación de las cuerdas para la venta.

Se usa como propiedad StringFormat en la entidad Cuerdas.

Valores disponibles:

  • Reel — Bobina o rollo (larga longitud, múltiples encordados).
  • Set — Juego individual (suficiente para una raqueta).
Valores de enumeraciones
Reel 

Bobina o rollo (200m / 660ft, múltiples encordados).

Set 

Juego individual (12m / 40ft, suficiente para una raqueta).

◆ MaterialType

enum BackEncordados.Materials.Model.MaterialType

Enum que clasifica los tipos de materiales de encordado disponibles en el inventario.

Se usa como propiedad Type en la entidad Material para categorizar cada producto dentro del inventario.

Valores disponibles:

  • Grip — Grips o empuñaduras para raquetas.
  • Overgrip — Sobregrips (cinta fina sobre el grip base).
  • LeadTape — Cinta de plomo para ajuste de peso/balance.
  • Silicone — Amortiguadores de silicona para vibraciones.
  • Bumper — Protectores de cabeza de raqueta.
  • Otro — Cualquier otro material no categorizado.
Valores de enumeraciones
Grip 

Grip o empuñadura para raquetas.

Overgrip 

Sobregrip (cinta fina sobre el grip base).

LeadTape 

Cinta de plomo para ajuste de peso y balance.

Silicone 

Amortiguador de silicona para reducción de vibraciones.

Bumper 

Protector de cabeza (bumper) para raquetas.

Otro 

Otros materiales no categorizados.

◆ StringsType

enum BackEncordados.Materials.Model.StringsType

Enum que clasifica los tipos de cuerdas para raquetas según su material y construcción.

Se usa como propiedad StringsType en la entidad Cuerdas para categorizar el tipo de cordaje.

Valores disponibles:

  • Polyester — Cuerda de poliéster (alta durabilidad, poco confort).
  • Multifilament — Cuerda multifilamento (buen confort, potencia media).
  • SyntheticGut — Cuerda sintética tipo tripa (económica, versátil).
  • NaturalGut — Tripa natural (máximo confort y potencia, alto costo).
  • Hybrid — Encordado híbrido (combinación de dos tipos diferentes).
Valores de enumeraciones
Polyester 

Cuerda de poliéster: alta durabilidad, bajo confort, control.

Multifilament 

Cuerda multifilamento: buen confort, potencia media.

SyntheticGut 

Cuerda sintética tipo tripa: económica y versátil.

NaturalGut 

Tripa natural: máximo confort, mejor potencia, alto costo.

Hybrid 

Encordado híbrido: combina dos tipos de cuerda (ej: poliéster + tripa).
