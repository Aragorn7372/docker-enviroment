Descripción detallada

Contrato del administrador de archivos ZIP para exportación e importación completa de la base de datos del sistema.

Gestiona la creación y extracción de archivos ZIP que contienen los datos completos del sistema en formato JSON, organizados por módulo.

Estructura del archivo ZIP:

Archivo Contenido Serializador
users.json Usuarios del sistema (List<User>). Newtonsoft.Json
tournaments.json Torneos (List<Tournaments>). Newtonsoft.Json
materials.json Materiales de encordado (List<Material>). Newtonsoft.Json
cuerdas.json Cuerdas (List<Cuerdas>). Newtonsoft.Json
orders.json Pedidos (List<Pedidos>). Newtonsoft.Json
manifest.json Metadatos de exportación (ExportManifestDto). System.Text.Json

Los datos de entidades se serializan con Newtonsoft.Json (con ReferenceLoopHandling.Ignore) para manejar relaciones de navegación circulares de Entity Framework. El manifest se serializa con System.Text.Json (camelCase, indentado) por su simplicidad.

Todos los métodos trabajan con directorios temporales en TEMP% que se eliminan en bloques finally. Las excepciones se propagan hacia arriba después de la limpieza.

◆ CreateZipAsync()

Task< byte[]> BackEncordados.Export.Archive.IExportArchiveManager.CreateZipAsync ( ExportDataDto  data)

Crea un archivo ZIP con todos los datos de la base de datos en formato JSON.

Flujo:

  1. Crea un directorio temporal único en TEMP%.
  2. Serializa cada lista de entidades a JSON con Newtonsoft.Json y las escribe como archivos individuales (users.json, tournaments.json, etc.).
  3. Construye un ExportManifestDto con la fecha de exportación y metadatos de cada archivo (nombre, cantidad de registros).
  4. Serializa el manifest con System.Text.Json y lo escribe como manifest.json.
  5. Comprime todo el directorio temporal en un archivo ZIP mediante ZipFile.CreateFromDirectory.
  6. Lee el ZIP como arreglo de bytes y lo retorna.

El directorio temporal se elimina en el bloque finally.

Parámetros
dataDTO con todas las listas de entidades a exportar.
Devuelve
Arreglo de bytes con el archivo ZIP generado.

◆ ExtractZipAsync()

Task< ExportDataDto > BackEncordados.Export.Archive.IExportArchiveManager.ExtractZipAsync ( Stream  zipStream)

Extrae los datos de un archivo ZIP y los deserializa en un ExportDataDto.

Flujo:

  1. Crea un directorio temporal único en TEMP%.
  2. Guarda el stream de entrada como data.zip en el directorio temporal.
  3. Extrae el ZIP con ZipFile.ExtractToDirectory (sobrescribe archivos existentes).
  4. Lee cada archivo JSON con verificación de existencia (IOFile.Exists) y deserializa con Newtonsoft.Json a la lista correspondiente.
  5. Retorna el DTO con todas las listas pobladas.

Si algún archivo no existe en el ZIP, la lista correspondiente queda vacía (no lanza error). El directorio temporal se elimina en el bloque finally.

Parámetros
zipStreamStream del archivo ZIP a extraer.
Devuelve
DTO con todas las entidades deserializadas.

◆ GetManifestAsync()

Task< ExportManifestDto > BackEncordados.Export.Archive.IExportArchiveManager.GetManifestAsync ( byte[]  zipData)

Obtiene el manifest de un archivo ZIP sin extraer los datos completos.

Flujo:

  1. Escribe el arreglo de bytes a un archivo ZIP temporal.
  2. Abre el ZIP como ZipArchive en modo lectura.
  3. Busca la entrada manifest.json dentro del archivo.
  4. Si no existe → lanza InvalidOperationException.
  5. Lee y deserializa el manifest con System.Text.Json.

Útil para previsualizar el contenido de un ZIP sin extraer todos los datos. El archivo temporal se elimina en el bloque finally.

Parámetros
zipDataArreglo de bytes del archivo ZIP.
Devuelve
Manifest con metadatos de la exportación.
Excepciones
InvalidOperationExceptionEl archivo ZIP no contiene manifest.json o el manifest no pudo deserializarse.
