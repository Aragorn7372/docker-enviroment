Descripción detallada

Implementación de IWhatsAppService que envía mensajes a través de la WhatsApp Cloud API (Meta Graph API).

Utiliza la API de Meta para enviar mensajes de WhatsApp desde un número de negocio registrado en Meta Business Platform.

Configuración requerida (via AppConfig):

Propiedad Descripción Default
WhatsAppEnabled Habilita/deshabilita el envío de mensajes —
WhatsAppApiVersion Versión de la Graph API v21.0
WhatsAppPhoneNumberId ID del número de teléfono de negocio en Meta —

Comportamiento:

  • Si WhatsAppEnabled es false, todos los métodos retornan false sin enviar.
  • Si el número de teléfono está vacío, retorna false con warning.
  • Los mensajes de texto libre se envían como type: "text".
  • Las plantillas se envían con idioma "es_ES" (español).
  • Los errores HTTP y de red se capturan, loggean y retornan false (fail-safe).
Parámetros
loggerLogger para seguimiento de envíos y errores.
httpClientFactoryFábrica de HttpClient para named client "WhatsApp" (con token de acceso configurado en DI).

Envía un mensaje de texto libre a un número de teléfono vía WhatsApp Cloud API.

Flujo:

  1. Verifica si el servicio está habilitado (IsEnabled).
  2. Valida que el número de teléfono no esté vacío.
  3. Normaliza el número (NormalizePhoneNumber).
  4. Construye payload { messaging_product: "whatsapp", type: "text", text: { body } }.
  5. Envía la petición HTTP mediante SendWhatsAppRequestAsync.
Parámetros
phoneNumberNúmero de teléfono del destinatario.
messageTexto del mensaje.
Devuelve
true si el mensaje se envió correctamente.

Envía una plantilla de mensaje aprobada por Meta con parámetros opcionales.

Flujo:

  1. Verifica si el servicio está habilitado.
  2. Valida y normaliza el número de teléfono.
  3. Construye payload type: "template" con name, language.code: "es_ES" y componentes de tipo body con los parámetros proporcionados.
  4. Envía la petición HTTP.

Si no se proporcionan parámetros, el componente se envía como null.

Parámetros
phoneNumberNúmero de teléfono del destinatario.
templateNameNombre de la plantilla en Meta Business Manager.
parametersParámetros para reemplazar variables {{1}}, {{2}}, etc. en la plantilla.
Devuelve
true si la plantilla se envió correctamente.
