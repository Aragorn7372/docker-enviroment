Descripción detallada

Interfaz genérica del servicio base para productos (materiales y cuerdas).

Parámetros de plantilla
TTipo del DTO de respuesta.
ETipo del error (hereda de DomainErrors).
RTipo del DTO de request para creación.
PTipo del DTO de request para actualización.
FTipo del DTO de filtro.

Define las operaciones de negocio estándar para productos del inventario, utilizando el patrón Result de CSharpFunctionalExtensions para manejo de errores.
