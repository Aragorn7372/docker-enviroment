record BackEncordados.Materials.Errors.CuerdaError ( string  Error)

Record base para errores del módulo de cuerdas/tensores (entidad Cuerdas). Agrupa todos los errores relacionados con el catálogo de cuerdas: búsqueda, creación, actualización y eliminación de registros de cuerdas.

Subtipos que heredan de este record:

  • ConflictError — HTTP 409, duplicados o violación de integridad referencial.
  • CuerdaNotFoundError — HTTP 404, cuerda no encontrada por Id.
  • ValidationError — HTTP 400, datos inválidos (marca vacía, precio negativo, etc.).

Estos errores son lanzados por CuerdaService y capturados por GlobalExceptionHandler.

ErrorMensaje descriptivo del error específico de cuerdas.
